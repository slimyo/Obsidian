# Python `print()` 用法详解
## 一、函数签名
```python
print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)
```

|参数 | 默认值 | 说明 |
|------|--------|------|
| `*objects` | — | 要输出的对象（任意多个，自动用 `str()` 转换） |
| `sep` | `' '`（空格） | 多个对象之间的分隔符 |
| `end` | `'\n'` | 输出结束符 |
| `file` | `sys.stdout` | 输出目标（可为文件对象等） |
| `flush` | `False` | 是否立即刷新缓冲区 |

## 二、基本参数用法
```python
print("Hello", "World")              # Hello World（默认空格分隔）
print("2026", "10", "05", sep="-")   # 2026-10-05
print("不换行", end=" | ")            # 不换行 | 接着打印
print()                              # 输出空行
print(*[1, 2, 3])                    # 解包列表 → 1 2 3
print(*range(5), sep=",")            # 0,1,2,3,4
print("写入文件", file=f)             # 输出重定向到文件
print("进度", flush=True)            # 立即刷新，适合实时输出
```
## 三、三种格式化方式
### 1️⃣ `%` 旧式格式化
```python
print("姓名: %s, 年龄: %d" % ("小明", 18))   # 姓名: 小明, 年龄: 18
print("分数: %.2f%%" % 95.678)               # 分数: 95.68%
print("%5d|%-5d|%05d" % (42, 42, 42))        # ␣␣␣␣42|42␣␣␣␣|00042
```
常用占位符：`%s` 字符串、`%d` 整数、`%f` 浮点、`%.2f` 两位小数、`%x` 十六进制、`%e` 科学计数法
### 2️⃣ `str.format()` 方法
```python
print("{} 岁".format(20))                        # 顺序填充
print("{1} 在 {0}".format("北京", "小李"))        # 位置索引 → 小李 在 北京
print("{name} {age}".format(name="小张", age=25)) # 关键字
print("{:>10}".format("右对齐"))                  # 右对齐占10宽
print("{:,}".format(1234567))                    # 1,234,567
print("{:.2%}".format(0.75))                     # 75.00%
```
### 3️⃣ f-string（Python 3.6+，⭐推荐）
```python
name, age = "小刚", 22
print(f"我叫{name}，明年{age + 1}岁")    # 可嵌入任意表达式
print(f"{3.14159265:.3f}")              # 3.142
print(f"{age=}")                        # age=22（调试利器，3.8+）
print(f"{d['a']}")                      # 可访问字典元素
```
## 四、格式说明符语法（通用）
```
{[填充][对齐][宽度][,][.精度][类型]}
```

| 语法 | 示例 | 输出 | 说明 |
|------|------|------|------|
| `>10` | `f"{'ab':>10}"` | `␣␣␣␣␣␣␣␣ab` | 右对齐（默认） |
| `<10` | `f"{'ab':<10}"` | `ab␣␣␣␣␣␣␣␣` | 左对齐 |
| `^10` | `f"{'ab':^10}"` | `␣␣␣␣ab␣␣␣␣` | 居中 |
| `*^10` | `f"{'ab':*^10}"` | `****ab****` | 自定义填充字符 |
| `.2f` | `f"{3.14159:.2f}"` | `3.14` | 保留2位小数 |
| `10.2f` | `f"{3.14159:10.2f}"` | `␣␣␣␣␣␣␣3.14` | 宽度+精度 |
| `,` | `f"{1234567890:,}"` | `1,234,567,890` | 千位分隔 |
| `.1%` | `f"{0.856:.1%}"` | `85.6%` | 百分比 |
| `b`/`o`/`x`/`X` | `f"{255:x}"` | `ff` | 二/八/十六进制 |
| `#x` | `f"{255:#x}"` | `0xff` | 带前缀进制 |
| `e` | `f"{12345.678:e}"` | `1.234568e+04` | 科学计数法 |
## 五、实用技巧
```python
# 打印进度条
for i in range(0, 101, 20):
    print(f"\r进度: [{'='*(i//5)}{(20-i//5)*' '}] {i}%", end="", flush=True)
# 变量同时打印名字和值（调试）
x, y = 10, 20
print(f"{x=}, {y=}, {x+y=}")   # x=10, y=20, x+y=30
# 打印到标准错误
import sys
print("错误信息", file=sys.stderr)
# 结构化输出
data = [("姓名", "年龄"), ("小明", 18), ("小红", 20)]
for name, age in data:
    print(f"{name:<6}{age:>4}")
```
**总结建议**：新代码统一使用 **f-string**（最简洁、性能最好），`format()` 适合模板复用场景，`%` 仅在维护老代码时使用。
